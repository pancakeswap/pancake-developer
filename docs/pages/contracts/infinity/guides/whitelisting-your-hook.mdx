# PancakeSwap Infinity Hook Whitelist Application

Complete this form to request a whitelist review for your PancakeSwap Infinity hook: [https://pancakeswap.finance/hooks-submission](https://pancakeswap.finance/hooks-submission)

Whitelisting makes pools deployed with custom hooks on PancakeSwap Infinity easier to find: they can be shown on the PancakeSwap website and routed through the aggregator.

Your hook should be deployed on mainnet with verified source code and fully tested. The form will ask for your project details, contract information, and a clear description of how the hook behaves.

Whitelisting is not an endorsement or a guarantee of the hook's security. Users should still do their own research.
