## MultiReactor Router

One stable proxy address per wallet family fills **all** order types (ExclusiveDutch / V3Dutch / V4Dutch and future types). Resolve the order type by decoding the order, then call the typed / by-type function — see [Overview](/contracts/pcsx/overview#whats-new-multireactor-router--v4dutch).

## ExclusiveDutchOrderReactor

_Legacy standalone reactor — valid for in-flight orders only._

`ExclusiveDutchOrderReactor` facilitates the execution of exclusive Dutch orders, which are a type of order where the execution price decays linearly over time, similar to a Dutch auction.

This reactor introduces a period of exclusivity before the price decay begins, granting a specific filler exclusive rights to fulfill the order within this timeframe.

## V3DutchOrderReactor

_Legacy standalone reactor — valid for in-flight orders only._

`V3DutchOrderReactor` executes V3 Dutch orders, an iteration of the Dutch order design used by PancakeSwapX for more flexible, gas-efficient price decay curves.
